# 🍪 Project: The Sovereign Cookie Jar
A high-performance, audio-synced interactive portfolio interface designed for the **Foozi** ecosystem. This isn't just a UI component; it’s a **Harmonic Engine** built to demonstrate technical resourcefulness, systems thinking, and consumer delight.
## 🚀 The Signal (Core Features)
 * **Harmonic Engine (Web Audio API):** A custom-built audio orchestrator that maps user interactions to a dynamic **Circle of Fifths** progression. Every "flip" advances the scale, providing auditory feedback that signals mathematical intent.
 * **Heartbeat Jitter (Framer Motion):** A calibrated "click-me" animation loop. Designed to feel "excited yet focused," replacing generic hover effects with a rhythmic, lifelike pulse.
 * **The Sovereign Transition:** A state-dependent UI shift. After a prolonged dwell time (High-Intent Signal), the primary CTA undergoes a Crimson-and-Gold transformation, signaling "S-Tier" depth.
 * **Zero-Cost Scalability:** Built to live on Oracle Cloud ARM infrastructure, optimized for high performance with minimal overhead.
## 🛠️ Technical Stack
 * **React + Framer Motion:** For complex, interruptible physics-based animations.
 * **Web Audio API:** Low-latency oscillator management for real-time scale generation.
 * **Tailwind CSS:** For the "Cloud Mansion" glassmorphism aesthetic and high-contrast typography.
