# 🍪 Project: The Sovereign Cookie Jar

## What this is

The Sovereign Cookie Jar is an interactive portfolio component built for Vivian Yang's portfolio.

On the surface, it feels playful and a little magical. Underneath, it is a real technical system combining motion, sound, state changes, and layered interaction design. It was built to show the kind of products I like making: memorable, intentional, and genuinely fun to explore.

This is not just a decorative widget. It is a small product experience.

## Why I made it

Most portfolios are passive. You scroll, skim, and move on.

I wanted to build something that rewards curiosity instead. The Cookie Jar turns a portfolio into a discovery moment. The interaction itself becomes part of the story, and the person clicking gets a better sense of how I think about engineering, product feel, delight, and signal.

It is meant to communicate that I do not only build things that function. I build things that feel alive.

## 🚀 The Signal

### Harmonic interaction engine
A custom Web Audio layer maps user actions to a musical progression, so each flip feels responsive and intentional instead of random.

### Heartbeat Jitter motion
The animation system replaces generic hover behavior with a pulse that feels excited, focused, and slightly alive.

### Sovereign transition
After a longer dwell time, the main CTA shifts into a Crimson-and-Gold state. It creates a small sense of payoff and discovery without changing the core structure.

### High-performance visual design
The component is built to feel rich while staying lightweight, using glassmorphism, motion, and contrast carefully rather than just piling on effects.

## 🛠️ Technical Stack

- **React**
- **Framer Motion** for interruptible, physics-based animation
- **Web Audio API** for low-latency harmonic feedback
- **Tailwind CSS** for styling and glassmorphism treatment

## 🎼 The interaction logic

The jar does not play random sounds. It follows a structured path:

1. It begins in **C Major**
2. Each interaction advances the progression
3. The harmonic tension builds over time
4. Once it reaches the ceiling, it resets with a glissando so the experience stays satisfying instead of becoming noisy
